# Dragonfire Project Context

This directory is generated by `npm run export:context`.

It contains the current simple product context: dragon identity metadata, raw verified ability wording, curated simple synergy profiles, profile-audit dispositions, Formation Rating v3 reliability/scoring/placement rules, evidence, manual reviews, glossary entries, and stat definitions.

It intentionally excludes retired combat-analysis artifacts such as capability matrices, expected interactions, execution schedules, rolls, and damage-simulation records. Narrow production reliability and recipient-targeting contracts required for current Formation Rating remain included.
