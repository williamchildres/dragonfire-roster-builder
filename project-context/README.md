# Dragonfire Project Context

This directory is generated by `npm run export:context`.

It contains the current simple product context: dragon identity metadata, raw verified ability wording, curated simple synergy profiles, profile-audit dispositions, Formation Rating v2 semantic/scoring/placement rules, evidence, manual reviews, glossary entries, and stat definitions.

It intentionally excludes retired combat-analysis artifacts such as capability matrices, traces, expected interactions, unresolved mechanic reports, schedules, rolls, target-selection groups, and damage-simulation records.
