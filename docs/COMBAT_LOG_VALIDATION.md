# Combat Evidence Verification

Dragonfire Roster Lab uses combat logs and screenshots only to verify source wording, unlocks, hard position requirements, evidence metadata, and high-level relationships that belong in curated simple synergy profiles.

It does not reconstruct exact combat execution. Do not use this process to model exact timing, roll scope, target overlap, stack refresh, damage formulas, expected damage, or win probability.

## What To Capture

- Dragon identity screen when identity, rarity, breed, affinities, or public roster status changes.
- Command, Trait, and Habit screenshots with full visible wording.
- Star Rank and Dragon Level unlock requirements.
- Hard position requirements, such as Vanguard-only Traits or flank-specific recipients.
- Evidence IDs, capture date, game build, and reviewer notes.

## What To Review

- Does the raw wording match the canonical ability text exactly apart from whitespace normalization?
- Does a simple profile need a new or updated high-level tag relationship?
- Does the profile audit disposition reference the real ability and any represented signal IDs?
- Does any note belong in existing evidence or manual-review metadata rather than source data?

## What Not To Add

Do not add capability matrices, traces, expected interaction files, unresolved mechanic exports, schedule structures, roll structures, target-selection groups, or damage simulation records.
